# ランキング機能のセットアップ手順（Google Apps Script）

壁よけタップゲームのランキングは、Google スプレッドシート + Google Apps Script (GAS) を
データベース代わりに使う簡易的な仕組みです。認証や不正投稿対策などのセキュリティは
一切考慮していません（お遊び用途）。

## 1. スプレッドシートを作成する

1. Google スプレッドシートで新しいシートを作成する（名前は何でもよい）
2. 「拡張機能」→「Apps Script」を開く

## 2. スクリプトを貼り付ける

1. 開いたApps Scriptエディタのデフォルトの `Code.gs` の中身を全部削除
2. このリポジトリの [`apps-script/Code.gs`](./Code.gs) の内容を丸ごと貼り付ける
3. 上部の保存アイコンで保存する（プロジェクト名は何でもよい）

## 3. ウェブアプリとしてデプロイする

1. 右上の「デプロイ」→「新しいデプロイ」をクリック
2. 種類の選択（歯車アイコン）で「ウェブアプリ」を選ぶ
3. 設定:
   - 説明: 任意（例: `ranking-v1`）
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
4. 「デプロイ」をクリック
5. 初回は権限の承認を求められるので、自分のGoogleアカウントで許可する
   （「このアプリは Google で確認されていません」という警告が出ますが、自分が作成した
   スクリプトなので「詳細」→「（プロジェクト名）に移動」で進めてOKです）
6. デプロイ完了後に表示される **ウェブアプリのURL**（`https://script.google.com/macros/s/.../exec` の形式）をコピーする

## 4. フロントエンドにURLを設定する

[`game.js`](../game.js) 内の以下の行を、コピーしたURLに書き換えてください。

```js
const RANKING_API_URL = 'YOUR_GAS_WEB_APP_URL_HERE';
```

↓

```js
const RANKING_API_URL = 'https://script.google.com/macros/s/xxxxxxxxxxxxxxxx/exec';
```

保存してブラウザをリロードすれば、ミニゲーム下にランキングが表示され、
TOP10入りするとニックネーム登録フォームが出るようになります。

## 5. スクリプトを更新したとき

`Code.gs` の中身を修正した場合は、Apps Scriptエディタ側のコードも書き換えたうえで、
「デプロイ」→「デプロイを管理」→ 対象のデプロイの鉛筆アイコン →
バージョンを「新バージョン」にして「デプロイ」を押し直してください。
（URLは変わりません）

## 補足

- シートの `Ranking` というタブに `timestamp / nickname / score` の3列で記録されます。
  データを消したい場合はスプレッドシート上で行を直接削除してください。
- 同じプレイヤーが何度も上位10位以上のスコアを出した場合、その都度別の記録として
  登録されます（重複排除はしていません）。
- ニックネームは10文字まで。空欄の場合は「名無し」として登録されます。
